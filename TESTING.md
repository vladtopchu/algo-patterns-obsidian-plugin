# Проверка версии 1.0.3

Проверено 31 октября 2026 года:

- TypeScript: `tsc --noEmit`.
- Сборка esbuild с внешним модулем `obsidian`; в плагин не включены Node.js API.
- Поведенческие тесты импорта, интервалов, очереди, таймера, сохранения и обработки конфликтов.
- Сценарий интерфейса в jsdom с тестовым адаптером Obsidian API: импорт → запуск таймера → подсказка → сохранение результата → статистика → повторное чтение данных.
- Восстановленный экран не блокирует готовность рабочего пространства.
- Установщик копирует только runtime-файлы и сохраняет существующий tracker.json.
- Настройки Obsidian: смена папки, параметры практики и сохранение после повторного запуска.
- Миграция старой папки с историей и таймером, конфликты путей, перенос заметок и бэкапов, откат при ошибках.
- Кнопка в шапке перечитывает изменения другого устройства из выбранной папки, обновляет все открытые экраны и позволяет продолжить сохранение; повреждённый файл не перезаписывается.
- Импорт произвольного каталога доступен на вкладке «Данные».
- Пакет содержит три runtime-файла и инструкцию.

Плагин не устанавливался в пользовательский vault. Тест с jsdom проверяет взаимодействие и DOM, но не является запуском внутри Obsidian и не проверяет визуальный вид на реальном устройстве. Мобильный Obsidian и синхронизация двух устройств вручную не проверялись.

Повторение проверок: `npm run package`.
